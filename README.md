# walkertonlivery.ca

Website for **The Walkerton Livery** — short-term accommodation at 11 Victoria
St. S, Walkerton, Ontario.

A reskin of the previous site: same pages, same words, rebuilt as clean static
HTML. The old site was generated by Plesk Web Presence Builder 12 (a 2014-era
tool) and shipped a 16 MB banner image.

## What changed

- **18 MB of images → 1 MB.** The banner alone was a 4080×2600 PNG at 16 MB; it
  is now a 1900px progressive JPEG. Room photos are resized and re-encoded.
- **Responsive.** Real mobile layout with a working menu, instead of a desktop
  page scaled down.
- **Findable.** Per-page titles and meta descriptions, canonical URLs, Open
  Graph tags for link previews, `LodgingBusiness` structured data, `sitemap.xml`
  and `robots.txt`. The old site had none of this.
- **Accessible.** Skip link, visible focus rings, alt text, real heading order,
  and `prefers-reduced-motion` respected.
- **No third-party anything.** No jQuery, no CDN, no web fonts, no trackers —
  one 8 KB stylesheet and ~20 lines of inline JS for the mobile menu.

Booking still hands off to Little Hotelier
(`app.littlehotelier.com/properties/thelivery`), as before.

### Content notes

The copy is carried over as-is apart from these, worth a glance:

- "Liverty" is corrected to "Livery" throughout (it appeared that way on most

- The About page sentence read "the original Kilmer Livery Stable build in b

- The Rates page said "Press the green checkmark to see rates and availabilty."

Nothing else was reworded. **Other Services** and **Things to do** still say
"Coming soon" — send me the content and I'll fill them in.

## Editing

Page content and navigation live in `build.js`, in the `pages` array. Styling is
`css/site.css`. Running the build regenerates `dist/`:

```bash
node build.js
```

No dependencies — Node 18+ built-ins only.

To preview locally:

```bash
node build.js && cd dist && python3 -m http.server 8000
```

## Deploying

`dist/` is the whole site: plain HTML, CSS and images, no server-side anything.

Upload the **contents** of `dist/` to the web root (Plesk → File Manager →
`httpdocs`, or over FTP). It works on the current LiteSpeed hosting as-is.

`dist/` is committed so the site can be uploaded without running the build.

The URLs match the old site exactly — `/about-us/`, `/rooms/`, `/rates/`,
`/local-services/restaurants/` and so on — so existing links and search results
keep working.

## Layout

```
build.js        page content + templates; writes dist/
css/site.css    the stylesheet
images/         optimized photos
dist/           generated site — this is what gets uploaded
```
